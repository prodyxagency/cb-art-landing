# CB Art Real Estate — Landing Page

Landing page de propiedades de lujo para Coldwell Banker Art Real Estate en la Costa del Sol.

## Gestión de propiedades
Las propiedades se gestionan desde Google Sheets. Para agregar, modificar o marcar como vendida una propiedad, editá la planilla directamente.

## Tecnología
- HTML/CSS/JS puro (sin frameworks)
- Google Sheets como CMS
- GTM-NQT8LNF4 para tracking
- Deploy automático via Vercel + GitHub
